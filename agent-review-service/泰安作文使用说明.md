## 1. 前置准备


```
agent-review-service/picture/泰安市高二年级期末考试/
├── xxx-201111001-背面.jpg
```

## 2. 生成数据集清单

### 2.1 全量生成
```bash
cd /Users/trentzhao/Documents/edu-arena-java/agent-review-service
python3 scripts/gen_dataset_taian.py \
  --pictures picture/泰安市高二年级期末考试 \
```

输出 `data/dataset_taian_hero.jsonl`（11559 条，已按学号聚合）。

### 2.2 小样本生成（首次强烈推荐）
```bash
python3 scripts/gen_dataset_taian.py \
  --pictures picture/泰安市高二年级期末考试 \
  --output  data/dataset_taian_hero_sample20.jsonl \
  --limit   20
```

### 2.3 参数说明

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `--pictures` | ✅ | —— | 图片根目录 |
| `--output`   | ✅ | —— | 输出 `.jsonl` 路径 |
| `--grade`    | ❌ | `高中` | 写入每条的 `grade_level` |
| `--limit`    | ❌ | `0` | 只取前 N 条，`0` = 不限制 |

## 3. 启动批量评审

### 方式 A：一键脚本（小批量 / 调试）
```bash
cd /Users/trentzhao/Documents/edu-arena-java/agent-review-service
./scripts/run_batch.sh -i data/dataset_taian_hero_sample20.jsonl -c 3
```

### 方式 B：分步手动（推荐，适合全量 1 万+）

**终端 1 —— 启动评审服务（常驻）**
```bash
cd /Users/trentzhao/Documents/edu-arena-java/agent-review-service
python3 -m app.main
# 默认监听 http://127.0.0.1:8100
```

**终端 2 —— 跑批（支持断点续跑）**
```bash
cd /Users/trentzhao/Documents/edu-arena-java/agent-review-service

# 🧪 先跑小样本 + dry-run（不回传 arena）
python3 -m batch.cli run \
  -i data/dataset_taian_hero_sample20.jsonl \
  -c 3 \
  --dry-run \
  --store data/batch_tasks_taian_sample.sqlite \
  -o      data/results_taian_sample.jsonl

# ✅ 验证 OK 后跑全量
python3 -m batch.cli run \
  -i data/dataset_taian_hero.jsonl \
  -c 5 \
  --store data/batch_tasks_taian.sqlite \
  -o      data/results_taian.jsonl
```

### 3.1 关键参数

| 参数 | 说明 |
|---|---|
| `-i`        | 输入清单 `.jsonl` |
| `-c`        | 并发数，建议 3–10 |
| `-o`        | 结果 `.jsonl` 输出（逐条追加，可随时查看） |
| `--store`   | SQLite 状态库，**断点续跑必传** |
| `--dry-run` | 只生成评审结果，不回写 Java arena |

## 4. 进度监控 / 断点续跑

```bash
# 查看任务状态统计（pending / running / done / failed）
python3 -m batch.cli status --store data/batch_tasks_taian.sqlite

# 中途 Ctrl+C 后重跑同一命令 —— 已完成的自动跳过
python3 -m batch.cli run \
  -i data/dataset_taian_hero.jsonl \
  -c 5 \
  --store data/batch_tasks_taian.sqlite \
  -o      data/results_taian.jsonl

# 只重跑失败条目
python3 -m batch.cli run \
  -i data/dataset_taian_hero.jsonl \
  --store data/batch_tasks_taian.sqlite \
  --retry-failed \
  -o      data/results_taian.jsonl
```

## 5. 结果查看

`data/results_taian.jsonl` 每行一条：
```json
{
  "item_id": "essay-201111001",
  "status": "success",
  "scores": {"内容": 17, "语言": 16, "结构": 15, "文采": 14, "书写": 8, "立意": 17},
  "total": 87,
  "comment": "...",
  "elapsed_ms": 12843
}
```

快速统计：
```bash
# 成功 / 失败数
jq -r '.status' data/results_taian.jsonl | sort | uniq -c

# 平均总分
jq -r 'select(.status=="success") | .total' data/results_taian.jsonl \
  | awk '{s+=$1;n++} END{print "avg=",s/n," n=",n}'
```

## 6. ⚠️ 注意事项

| 事项 | 建议 |
|---|---|
| **费用预警** | 11559 条 ×（6 维度 `gpt-5-mini` + `gpt-5` 仲裁）单价约几分钱，全量需预估 API 额度 |
| **图片大小** | 单张 base64 化较大，5 并发足够；过高易触发限流 |
| **网络中断** | 所有任务幂等，Ctrl+C 后重跑同一命令即可 |
| **首次调试** | 务必 `--limit 20 + --dry-run` 走通全链路再上全量 |
| **Java Arena** | 非 dry-run 模式需 Spring 主应用在 `localhost:5001` 运行 |
| **日志** | 评审服务终端会打印每条耗时、失败原因 |
